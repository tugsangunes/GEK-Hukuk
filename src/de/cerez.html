Cookie-Richtlinie

Diese Website setzt selbst keine Cookies. Alle Dateien einschließlich der Schriftarten werden vom eigenen Server der Website geladen; Dienste Dritter zur Besucherverfolgung oder für Werbung gibt es nicht.

Karte

Die Karte auf der Kontaktseite wird erst geladen, wenn Sie auf „Karte anzeigen“ klicken. Dann wird die Karte von Google Maps (Google LLC) geladen; dabei werden Verbindungsdaten wie Ihre IP-Adresse an Google übermittelt, und Google kann eigene Cookies in Ihrem Browser setzen. Informationen zur Verarbeitung dieser Daten finden Sie in der Datenschutzerklärung von Google. Unsere Adresse können Sie auch ohne Laden der Karte über den Link „In Google Maps öffnen“ aufrufen.
